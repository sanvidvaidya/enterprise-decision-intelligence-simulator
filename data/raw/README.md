# Synthetic source extracts

Files in this folder are generated by:

```powershell
$env:PYTHONPATH = "src"
python -m decision_intelligence.generate_data
```

They imitate exports from four organizational systems. They are intentionally not loaded into SQLite in Phase 2; Phase 3 will validate and ingest them, recording any data-quality exceptions.

The generated CSV files are excluded from Git. The deterministic generation code is versioned, allowing any GitHub user to recreate exactly the same demo dataset.
